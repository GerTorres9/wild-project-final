## Sobre el proyecto

**Wild Project** es un sitio web Front-End multipágina desarrollado para representar una organización dedicada al rescate y adopción responsable de animales.

El proyecto ofrece información sobre adopción, bienestar animal y conciencia ambiental mediante una interfaz adaptable a diferentes dispositivos.

Durante su desarrollo se trabajó con HTML semántico, Sass, Bootstrap y JavaScript, poniendo especial atención en el diseño responsive, la experiencia de usuario y la interactividad mediante manipulación del DOM.

## Funcionalidades

- Diseño responsive para dispositivos móviles, tablets y escritorio.
- Navegación entre múltiples páginas.
- Catálogo de animales disponibles para adopción.
- Filtrado dinámico de animales por categoría.
- Modales interactivos mediante Bootstrap.
- Validación de formularios del lado del cliente.
- Contadores y elementos animados.
- Navegación responsive.
- Desplazamiento suave entre secciones.
- Botón dinámico para regresar al inicio.
- Organización modular de estilos mediante Sass.

## Instalación

Clona el repositorio:

```bash
git clone https://github.com/GerTorres9/wild-project-final.git
```

Accede al directorio del proyecto:

```bash
cd wild-project-final
```

Instala las dependencias de desarrollo:

```bash
npm install
```

Para trabajar con Sass y compilar automáticamente los cambios:

```bash
npm run sass:watch
```

Para generar la versión compilada de los estilos:

```bash
npm run sass:build
```

Posteriormente puedes abrir `index.html` directamente en el navegador o utilizar un servidor local como **Live Server**.

> Node.js se utiliza únicamente como herramienta de desarrollo para la gestión y compilación de Sass. El sitio está desarrollado con HTML, Sass, Bootstrap y JavaScript.
